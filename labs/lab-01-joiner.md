# Lab 1: Joiner — New User Provisioning

## Objective

Practice creating a new user identity and verifying security group membership in Microsoft Entra ID.

## Scenario

A new employee, Jordan Lee, joins the organization and needs an identity account and appropriate access.

## Environment

- **Platform:** Microsoft Entra ID
- **Lab type:** Identity and Access Management (IAM)
- **Test user:** Jordan Lee

## Tasks Completed

1. Created the Jordan Lee test account in Microsoft Entra ID.
2. Verified the user account.
3. Added Jordan Lee to the `NS-IT-Support` security group.
4. Verified the user's membership in the group.

## Results

- **User creation:** Completed
- **Account verification:** Completed
- **Security group membership:** Verified
- **Lab status:** Completed

## IAM Concepts Practiced

- User provisioning
- Identity administration
- Security group management
- Access assignment and verification
- Joiner lifecycle workflow

## Lessons Learned

This lab provided hands-on practice creating a user identity and verifying group membership in Microsoft Entra ID. These tasks are foundational to the Joiner stage of the Joiner-Mover-Leaver (JML) identity lifecycle.

## Security Notes

This project uses a test identity in a learning environment. No passwords, access tokens, or other sensitive credentials should be published.
