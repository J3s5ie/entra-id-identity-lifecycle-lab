# entra-id-identity-lifecycle-lab
Hands-on Microsoft Entra ID IAM lab covering identity provisioning, security groups, and access lifecycle management

## Project Overview

This project demonstrates hands-on Identity and Access Management (IAM) tasks using Microsoft Entra ID. It documents identity lifecycle management, user provisioning, security group membership, and access control.

## Objectives

- Create and manage user accounts.
- Verify user account details.
- Manage security group membership.
- Practice Joiner, Mover, and Leaver (JML) identity lifecycle workflows.
- Document access management procedures and verification steps.

## Lab Environment

- **Identity platform:** Microsoft Entra ID
- **Operating system:** macOS
- **Project type:** Hands-on IAM lab
- **Documentation:** GitHub

## Lab 1: Joiner — New User Provisioning

**Scenario:** A new employee joins the organization and requires an identity account.

**Tasks performed:**
- Created a test user named Jordan Lee in Microsoft Entra ID.
- Verified the account in the lab environment.
- Added the user to the `NS-IT-Support` security group.
- Verified the user's group membership.

**IAM concepts demonstrated:** Identity provisioning, user account management, security groups, and access assignment.

## Lab 2: Mover — Role or Department Change

**Scenario:** An employee changes roles or departments and requires updated access.

**Planned tasks:**
- Define the employee's new role.
- Review existing group memberships and access.
- Update access to reflect the new responsibilities.
- Verify the updated permissions.
- Document the changes.

**Status:** In progress.

## Lab 3: Leaver — Employee Offboarding

**Scenario:** An employee leaves the organization and should no longer have access.

**Planned tasks:**
- Disable the test user account.
- Review and remove access as appropriate for the scenario.
- Verify that the account is disabled.
- Document the offboarding process.

**Status:** Planned.

## Skills Demonstrated

- Microsoft Entra ID
- Identity lifecycle management
- User provisioning and account administration
- Security group membership management
- Access control fundamentals
- IAM documentation and verification
- Joiner, Mover, and Leaver (JML) workflows

## Notes

This is a personal learning project using a lab environment and test identities. It is intended to demonstrate IAM concepts and hands-on practice, not production administration.
